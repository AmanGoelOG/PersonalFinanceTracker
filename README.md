# PersonalFinanceTracker
PersonalFinanceTracker is a console-based C++ application designed to help users manage their personal finances efficiently. The project is built using Object-Oriented Programming (OOP) principles in C++, ensuring modularity, scalability, and clean code structure.

Features:
User Authentication – Secure login and user management
EMI & Loan Management – Calculate and track loan EMIs
Tax Report Section – Generate basic tax-related reports
Savings Goals – Set, monitor, and achieve financial goals
Expense & Income Tracking – Keep track of daily financial activities
User-Specific Data Handling – Personalized finance records

Technologies Used:
Language: C++
Programming Paradigm: Object-Oriented Programming (OOP)

Concepts Implemented:
Classes & Objects
Encapsulation
Inheritance
Abstraction
Exceptional Handling
File Handling 

Project Objective:

The goal of this project is to demonstrate practical implementation of OOP concepts in C++ while solving real-world personal finance management problems. It serves as both a learning project and a functional financial tracking tool.
